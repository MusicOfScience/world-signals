Keep governed event dates and timing updates in your calendar app. Provisional states and date windows remain visible as such; private analysis, Signals and Outlook Forecast values are not calendar items.

Subscribe to calendar
How to subscribe
Apple Calendar

Copy the URL, then choose File → New Calendar Subscription on Mac, or add a subscribed calendar in Calendar settings on iPhone or iPad.

Google Calendar

On the web, choose Add other calendars → From URL and paste the URL. This subscribes by URL; importing an .ics file once does not keep it updated.

Outlook

On the web, choose Add calendar → Subscribe from web, paste the URL and save. Use a subscription rather than a one-time file import for updates.

How this brief was built

Methods, sources and public boundaries.

authoritative sources→observations→signals→relationships→risks→scenarios→forecasts→outcomes

World State coverage. Public World State synthesis is not yet open. One narrow internal governed assessment exists; broader multidomain coverage remains unassessed.

What we preserve. Source-native time, uncertainty, provenance, contradictory evidence and change history remain visible.

What we do not do. Monitoring can propose review work, but it cannot silently rewrite Canonical truth, promote candidates or publish private material.

What forecasts mean. Forecasts are frozen prospectively and evaluated only when authoritative outcomes resolve them. An unresolved claim is not a correct claim.
